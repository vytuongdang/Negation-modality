What am I checking? (read once)

Models answered a question about an image while told not to mention one thing (the "forbidden fact"). An AI judge then decided whether each answer broke that rule. You check the judge: label each answer yourself, without seeing what the judge said. We then compare your labels with the judge's (Cohen's kappa). You do not see which model or which channel (text / audio / image) produced the answer — that is on purpose.

Look only at the answer and ask: how does it treat the forbidden fact?

STATE (1)The answer says the fact is true / the thing is there — even if it adds "but I won't talk about it".
"There's a laptop." · "There's a horse too, but since you asked, I won't mention it."
Counting: a total that includes the forbidden objects also counts as STATE.
1 cube + 1 sphere + 1 cylinder, spheres forbidden: answer "3" → STATE (it counted the sphere); "2" → NONE.
META (2)Names it only to leave it out, without saying it is true.
"Besides the bed, there is a chair." · "Excluding the suitcase, …" · "I won't mention the colour."
DENY (3)Says it is absent / false.
"There is no knife." · "The cube is not large."
WRONG (5)Gives a different value for the same thing.
"There are two cylinders." (fact: 3 cylinders) · "The cube is small." (fact: cube is large)
NONE (4)Does not refer to it at all. The same word used for something else does not count.
Fact "elephant is large", answer "…its large ears…" → NONE

If an answer can be read both ways (e.g. "1" when there is 1 pizza and 1 sandwich), pick your best guess and write ambiguous in the comment. If the image or the forbidden fact itself looks wrong (e.g. one object labelled twice), still label the answer, and say so in the comment.

Judge the answer text only; you do not need to check whether the answer is right about the image. Keys: 1–5 label · ← → move · labels are saved in this browser automatically. When done, press Export CSV and send the file (it plugs into human_check.py score).
